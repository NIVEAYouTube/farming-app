# Farming 農業コミュニティ（コンペ提案用プロトタイプ）

市民農園を地域の交流と地元企業との連携の拠点にする提案のための、オンラインコミュニティアプリの試作です。

- 公開URL：GitHub Pages を有効にすると `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます
- iPhone：Safariで開き、共有ボタン →「ホーム画面に追加」でアプリとして起動できます
- 写真・データはすべて `index.html` に埋め込み済みのため、オフラインの会場でも表示されます

## 主な機能
ホーム（府県別の投稿フィード）／掲示板（イベント・企業コラボ・募集・おすそわけ）／チャット（フレンド・グループ）／マイページ（収穫記録・予定カレンダー・各種設定）

※ 発表用の試作のため、データは端末内だけで動作し、サーバーには保存されません。
